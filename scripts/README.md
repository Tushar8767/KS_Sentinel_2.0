# Development Helper Scripts

**Module:** 0 — Architecture Foundation  

---

## Available Scripts

### `node scripts/start-dev.js` (or `npm run dev`)
Concurrently launches the Express Server Gateway on port 5000 and the React/Vite Client on port 5173.

---

## Execution Instructions

- **Run Client & Server Concurrently:** `npm run dev`
- **Run Client Only:** `npm run dev:client`
- **Run Server Only:** `npm run dev:server`
